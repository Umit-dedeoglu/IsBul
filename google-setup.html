Google OAuth Kurulum

işİşBul — Google ile giriş aktivasyonu

1️⃣ Google Cloud Console'a gidin

console.cloud.google.com → Proje oluşturun (işİşBul) → APIs & Services → OAuth consent screen

2️⃣ Credentials oluşturun

Create Credentials → OAuth client ID → Web application

Authorized redirect URIs:

http://localhost:3001/api/v1/auth/google/callback (Development)

https://isbul.online/api/v1/auth/google/callback (Production)

3️⃣ Bilgileri buraya girin

Client ID ve Client Secret'ı kopyalayıp aşağıya yapıştırın.

Sunucuyu yeniden başlaTümüanız gerekiyor (backend değişti).
Sonra Google ile giriş test edebilirsiniz.
